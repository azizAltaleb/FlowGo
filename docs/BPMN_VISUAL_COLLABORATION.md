# BPMN Tier-3 — Visual collaboration

Pools, lanes, data objects/stores, text annotations, and associations are **visual-only** in ArtificialFlow:

- The modeler can import/display documentation shapes (`visualArtifact` nodes).
- The runtime executes **process tokens** (tasks, events, gateways). Variables are the data model — not BPMN data objects.
- Do not claim executable Pool/Lane multi-party orchestration until the matrix row moves off Visual-only.

See [BPMN_SUPPORT_MATRIX.md](BPMN_SUPPORT_MATRIX.md).
